=== Estándares IEEE

* [[ieee-802-3]] IEEE, «IEEE Standard for Ethernet», IEEE Std 802.3.
  Cláusula 3, formato de la trama MAC; cláusula 14, MAU de par trenzado
  10BASE-T; cláusula 24 y 25, 100BASE-TX; cláusula 28, autonegociación;
  cláusula 33, alimentación por la MDI (802.3af y 802.3at); cláusula 40,
  1000BASE-T; cláusula 55, 10GBASE-T; cláusula 145, alimentación sobre las
  líneas de datos (802.3bt); cláusula 79, TLV LLDP y potencia por la MDI.

  Overview and Architecture — Amendment 1: Ethertypes for Prototype and Vendor
  Specific Protocol Development», IEEE Std 802a.

=== RFC

* [[rfc-791-ipv4]] J. Postel, «Internet Protocol», RFC 791 (STD 5), IETF, 1981.
  [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc791 [Último acceso: 2026].
* [[rfc-792-icmp]] J. Postel, «Internet Control Message Protocol», RFC 792 (STD 5),
  IETF, 1981. [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc792 [Último acceso: 2026].
* [[rfc-826-arp]] D. C. Plummer, «An Ethernet Address Resolution Protocol»,
  RFC 826 (STD 37), IETF, 1982.
  [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc826 [Último acceso: 2026].
* [[rfc-1071-internet-checksum]] R. Braden, D. Borman y C. Partridge, «Computing the Internet
  Checksum», RFC 1071, IETF, 1988.
  [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc1071 [Último acceso: 2026].
* [[rfc-2131-dhcp]] R. Droms, «Dynamic Host Configuration Protocol», RFC 2131,
  IETF, 1997. [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc2131 [Último acceso: 2026].
* [[rfc-768-udp]] J. Postel, «User Datagram Protocol», RFC 768 (STD 6), IETF, 1980.
  [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc768 [Último acceso: 2026].

* [[rfc-1945-http-1-0]] T. Berners-Lee, R. Fielding y H. Frystyk, «Hypertext Transfer Protocol—HTTP/1.0»,
  RFC 1945, IETF, 1996. [En línea]. Disponible:
  https://www.rfc-editor.org/rfc/rfc1945 [Último acceso: 2026].
* [[rfc-9110-http-semantics]] R. Fielding, M. Nottingham y J. Reschke, eds., «HTTP
  Semantics», RFC 9110, IETF, 2022.
  [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc9110 [Último acceso: 2026].
* [[rfc-9293-tcp]] W. Eddy, ed., «Transmission Control Protocol (TCP)», RFC 9293
  (STD 7), IETF, 2022. [En línea]. Disponible: https://www.rfc-editor.org/rfc/rfc9293 [Último acceso: 2026].

RFC 1071 no corresponde a ningún protocolo de la lista, pero define el
algoritmo del checksum de complemento a uno que comparten IPv4, ICMP, TCP y
UDP. Es la referencia que sostiene la sección de saneado, donde se explica que
los checksums se reparan de dentro hacia fuera.
